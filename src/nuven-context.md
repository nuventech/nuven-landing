NUVEN_CONTEXT.md

1. Identidad Central de Nuven
   Nuven no es solo una "fábrica de software"; es un socio tecnológico que transforma el caos operativo en sistemas claros y eficientes.

Lema: "Del caos al orden."

Filosofía: El software debe adaptarse al negocio, no el negocio al software.

Enfoque: Transparencia total, acompañamiento real y evolución por etapas.

Fundadores: Alejo y Davi (Orígenes en fotografía/cine con REC/LAB -> Alta sensibilidad estética visual).

2. Guía de Estilo Visual (UI/UX)
   La estética debe evocar sofisticación técnica, orden y modernidad.

Paleta de Colores (Estricta)
Fondo Principal (Deep Charcoal): #0A0A0A (Evitar negro absoluto #000000 para fondos, usarlo para contrastes).

Fondo Secundario (Surface): #121212 o #1A1A1A (Para tarjetas o secciones alternas).

Acento Principal (Electric Lime): #CCFF00

Uso: Botones primarios (CTA), estados activos, íconos clave, hovers.

Regla: Usar con moderación para guiar el ojo. No saturar.

Texto Principal: #FFFFFF (Blanco puro para encabezados).

Texto Secundario: #A1A1A9 (Gris claro para párrafos/body).

Bordes: border-neutral-800 (Sutiles).

Tipografía
Fuentes: Inter o Plus Jakarta Sans.

Estilo: Sans-serif, geométrico, limpio.

Componentes & Layout
Grid: Estilo "Bento Grid" (Cajas organizadas asimétricamente).

Formas: Bordes sutilmente redondeados (rounded-md o rounded-lg), nunca completamente redondos a menos que sean botones "pill".

Efectos: Glassmorphism muy sutil (backdrop-blur) en Navbars o modales. Glows suaves en color #CCFF00 al hacer hover.

3. Tech Stack & Reglas de Código
   Todo el código generado debe seguir estas preferencias técnicas:

Framework: Next.js (App Router).

Estilos: Tailwind CSS.

Animaciones:

GSAP: Para animaciones complejas, timelines y el concepto "Caos vs. Orden" (elementos que se organizan magnéticamente).

Framer Motion: Para transiciones de UI (modales, fade-ins al hacer scroll).

Iconografía: lucide-react.

4. Tono de Voz y Copywriting
   El contenido debe estar en Español.

Tono: Profesional pero cercano, técnico pero accesible. "Hablamos tu idioma, no solo código".

Palabras Clave: Sistemas, Claridad, Orden, Medida, Socio, Evolución, Escalable.

A Evitar: "Paquetes estándar", jerga técnica innecesaria sin explicación, promesas de "magia".

Narrativa: Enfocarse en el dolor del cliente (Excel desordenado, procesos manuales) y presentar a Nuven como la solución que trae paz mental y eficiencia.

5. Servicios Core (Para Contexto)
   Si se pide generar contenido sobre servicios, basarse en estos 4 pilares:

Gestión Interna: Dashboards y CRMs a medida para centralizar operaciones.

Apps Web & Desktop: Soluciones potentes (React/Electron).

E-commerce: Tiendas online con lógica de negocio compleja.

Integraciones: Conectar herramientas existentes (APIs) para automatizar flujos.

6. Instrucciones de Comportamiento para la IA
   Rol: Actúa como un Desarrollador Senior Frontend y Diseñador de Producto con experiencia en agencias B2B high-end.

Generación de UI: Prioriza siempre el "Dark Mode". Si no se especifica, asume fondo oscuro #0A0A0A con acentos #CCFF00.

Accesibilidad: Asegúrate de que el texto sobre el verde #CCFF00 sea oscuro (negro) para garantizar contraste legible.

Creatividad: Al sugerir animaciones, busca metáforas visuales de organización (cosas dispersas que se alinean).
